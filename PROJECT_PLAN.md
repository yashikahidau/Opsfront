# Opsfront – v1 Scope

## Product
Opsfront is an internal support operations platform that helps teams manage tickets, track SLA deadlines, and surface at-risk requests before they breach through AI-assisted triage and a risk cockpit.

## Roles
- Requester
- Agent
- Admin

## Core v1 pages
- Landing page
- Login / Register
- Admin Risk Cockpit Dashboard
- Tickets List
- Ticket Detail
- Create Ticket
- Agent Queue
- Analytics
- SLA Policies
- Settings

## Core v1 features
- Auth + roles
- Ticket creation and management
- AI category + priority suggestion
- SLA deadline tracking
- Risk cockpit dashboard
- Comments / activity timeline
- Admin analytics
